# LegendaryForge

LegendaryForge is a high-performance Minecraft Paper plugin for version 1.21.11 that adds 15 unique legendary items, including a full armor set, 5 maces, 5 spears, and a special weapon. Each item features 2 distinctive powers with custom particle effects, sounds, lore, and cooldown management. Built with PersistentDataContainer for secure item identification and a unified event listener for optimal performance.

## Install

1. Download the latest LegendaryForge JAR file.
2. Place the JAR file into your server's `plugins` folder.
3. Restart your Paper server (version 1.21.11 or later).

## Use

1. Start your Paper server with LegendaryForge installed.
2. Use the command `/legendaries give <player> <item_id>` to give legendary items to players.
3. Use `/legendaries list` to see all available item IDs.
4. Equip armor pieces to activate passive abilities, and right-click (or sneak+right-click for armor) to trigger active powers.
5. Attack enemies with legendary weapons to trigger on-hit effects.
